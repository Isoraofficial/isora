Tabel Identitas Trigonometri

Identitas Rumus
Pythagoras
Pythagoras dasar$\sin^2 \theta + \cos^2 \theta = 1$
Tangen–sekan$1 + \tan^2 \theta = \sec^2 \theta$
Kotangen–kosekan$1 + \cot^2 \theta = \csc^2 \theta$
Sudut Negatif
Sinus ganjil$\sin(-\theta) = -\sin \theta$
Kosinus genap$\cos(-\theta) = \cos \theta$
Tangen ganjil$\tan(-\theta) = -\tan \theta$
Kofungsi
Sinus ↔ kosinus$\sin(90° - \theta) = \cos \theta$
Kosinus ↔ sinus$\cos(90° - \theta) = \sin \theta$
Tangen ↔ kotangen$\tan(90° - \theta) = \cot \theta$
Penjumlahan dan Selisih
Sinus jumlah$\sin(A + B) = \sin A \cos B + \cos A \sin B$
Sinus selisih$\sin(A - B) = \sin A \cos B - \cos A \sin B$
Kosinus jumlah$\cos(A + B) = \cos A \cos B - \sin A \sin B$
Kosinus selisih$\cos(A - B) = \cos A \cos B + \sin A \sin B$
Tangen jumlah$\tan(A + B) = \dfrac{\tan A + \tan B}{1 - \tan A \tan B}$
Tangen selisih$\tan(A - B) = \dfrac{\tan A - \tan B}{1 + \tan A \tan B}$
Sudut Rangkap
Sinus rangkap dua$\sin 2\theta = 2 \sin \theta \cos \theta$
Kosinus rangkap dua$\cos 2\theta = \cos^2 \theta - \sin^2 \theta = 1 - 2\sin^2 \theta = 2\cos^2 \theta - 1$
Tangen rangkap dua$\tan 2\theta = \dfrac{2 \tan \theta}{1 - \tan^2 \theta}$
Setengah Sudut
Sinus setengah$\sin \dfrac{\theta}{2} = \pm \sqrt{\dfrac{1 - \cos \theta}{2}}$
Kosinus setengah$\cos \dfrac{\theta}{2} = \pm \sqrt{\dfrac{1 + \cos \theta}{2}}$
Tangen setengah$\tan \dfrac{\theta}{2} = \dfrac{\sin \theta}{1 + \cos \theta} = \dfrac{1 - \cos \theta}{\sin \theta}$
Perkalian ke Penjumlahan
Sinus × kosinus$\sin A \cos B = \dfrac{1}{2}\left[\sin(A+B) + \sin(A-B)\right]$
Kosinus × sinus$\cos A \sin B = \dfrac{1}{2}\left[\sin(A+B) - \sin(A-B)\right]$
Kosinus × kosinus$\cos A \cos B = \dfrac{1}{2}\left[\cos(A+B) + \cos(A-B)\right]$
Sinus × sinus$\sin A \sin B = -\dfrac{1}{2}\left[\cos(A+B) - \cos(A-B)\right]$
Penjumlahan ke Perkalian
Sinus + sinus$\sin A + \sin B = 2 \sin \dfrac{A+B}{2} \cos \dfrac{A-B}{2}$
Sinus − sinus$\sin A - \sin B = 2 \cos \dfrac{A+B}{2} \sin \dfrac{A-B}{2}$
Kosinus + kosinus$\cos A + \cos B = 2 \cos \dfrac{A+B}{2} \cos \dfrac{A-B}{2}$
Kosinus − kosinus$\cos A - \cos B = -2 \sin \dfrac{A+B}{2} \sin \dfrac{A-B}{2}$
